# 황금돼지 사주 (Golden Pig Saju)

**배포**: https://goldenpigsaju.vercel.app/ | **소스**: https://github.com/typ0307/golden-pig-saju

생년월시만 입력하면 사주팔자를 짚어주고, 성격 · 재물운 · 직업운을 따뜻하게
풀이해 주는 웹 서비스입니다. 만세력은 한국천문연구원 공공데이터포털 데이터
기반으로 산출합니다.

## 기술 스택

- Next.js (App Router) + TypeScript + Tailwind CSS
- zod + react-hook-form (입력 검증)
- Vercel AI SDK — 풀이 결과 스트리밍
- pnpm

## 기능

- **만세력 산출** — 한국천문연구원 음양력·24절기 데이터 기반 4주 팔자 · 오행 분포 · 일간
  - 연주는 입춘, 월주는 12절입의 절입 시각 기준
  - 한국 표준시와 서울 자오선의 30분 시차를 보정한 시두법 적용
- **사주 풀이** — 성격 · 재물운 · 직업운 순서로 실시간 스트리밍
- **추가 질문** — 풀이 후 3회 추가 질문 가능 (150자 제한)
- **메일로 받아보기** — 풀이 결과를 이메일로 발송 (받고 싶은 사람만)
- **로봇 방지** — Cloudflare Turnstile

입력 정보는 풀이 생성에만 사용되고 저장되지 않습니다.

## 시작하기

```bash
pnpm install
cp .env.example .env.local   # 키 입력
pnpm dev
```

필요한 환경 변수와 발급 방법은 `.env.example`의 주석을 참고하세요.
